# RIFTWAKE

RIFTWAKE is an original browser game built around a time-echo mechanic: record your movement, leave an Echo behind, then use that past version of yourself to manipulate the level while you move in the present.

## Play
Open `game/index.html` or use the GitHub Pages site.

## Controls
- WASD / Arrow Keys — move
- SPACE — record/release Echo
- R — restart
- ENTER — next fracture

## Website
The root `index.html` is the official landing page with update logs and a source-download button.
